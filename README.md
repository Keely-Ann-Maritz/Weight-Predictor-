# Weight Predictor Application and Model

![Kotlin](https://img.shields.io/badge/Kotlin-1.9.0-blue?logo=kotlin)
![Android](https://img.shields.io/badge/Android-OS-green?logo=android)
![Jetpack Compose](https://img.shields.io/badge/Jetpack%20Compose-UI-blue?logo=jetpackcompose)
![TensorFlow Lite](https://img.shields.io/badge/TensorFlow%20Lite-ML-orange?logo=tensorflow)

The application allows users to enter their height in centimeters and receive a predicted weight value generated by a pre-trained TensorFlow Lite model, in real-time. The model is loaded locally from the application's assets and executed entirely on the device, ensuring a fast response and offline functionality.

## IDE 
1. Install Visual Studio Code : [https://code.visualstudio.com/download](https://code.visualstudio.com/download)
2. Install Android Studio : [https://developer.android.com/studio](https://developer.android.com/studio)

## How to run the application
1. Clone repository using GitHub Desktop or download the zip folder
2. Open the WeightPredictor applicaiton in Android Studio
3. Click the run icon in the top navigation bar
4. Once the user is welcomed with the MainActivity page, enter your height into the textfield
5. Select the Predict button
6. View the predicted weight based on the height entered.
